# Running this project on Replit

This is a React/Vite website. The **Start application** workflow runs `npm run dev`, serving the site on port 5000 for the Replit preview. No external service or app secret is required by the current frontend.

Dependencies are declared in `package.json` and `package-lock.json`. If they need to be restored, install them from the lockfile. For a production build, run `npm run build`.
